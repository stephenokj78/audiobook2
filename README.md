# 오디오북 2

PDF를 강의별 전문으로 분할하고 TXT·DOCX·SSML·낭독 순서 JSON을 다운로드하는 로컬 웹앱입니다. 한국어와 영어 구간은 각각 지정한 TTS 목소리로 합성하여 MP3로 연결합니다.

## 로컬 실행

Node.js 22.13 이상에서 `npm install` 후 `start-local.cmd`를 실행합니다. 터미널에 표시된 Local 주소를 여세요. 기본 주소는 http://localhost:3000/ 입니다.

- PDF 텍스트 추출과 파일 생성은 브라우저에서 수행합니다.
- 음성 생성은 기존 `https://texttomp3.autosdl.org/api/tts` 서버를 사용하므로 인터넷과 해당 서버가 필요합니다.
- 글자를 선택할 수 있는 PDF, 최대 60MB를 지원합니다. 스캔 PDF에는 먼저 OCR이 필요하며 글자가 없는 쪽을 화면에 표시합니다.
- 자동 강의 구분 뒤 시작 쪽을 직접 수정할 수 있습니다. 표지와 서문은 첫 강의에 포함합니다.
- 텍스트를 요약하거나 괄호 속 설명·영어를 제거하지 않습니다. 쪽번호 제거와 줄바꿈 연결, 성경 장절 표기를 정리합니다.
- Google 계정 연결은 포함하지 않습니다. 내려받은 DOCX를 Google Drive에서 Google Docs로 열 수 있습니다.
- 이 작업은 사용자의 요청에 따라 로컬로만 구현했으며 외부 배포는 하지 않았습니다.

## 검증

`npm test`는 분할 시 원문 보존, 페이지 경계, 영어 낭독 순서, 장절 변환 및 SSML을 검증합니다.

`node tests/pdf-integration.mjs <PDF 경로>`는 이번 성경신학 원본(128쪽)이 네 강의로 완전히 분할되는지 확인합니다. 생성한 검증 파일은 무시되는 `work/`에만 저장합니다.
